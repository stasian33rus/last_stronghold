# Отчёт: Этап 3.1 — Валькирия, три полноценные формы

Дата: 2026-10-23 · Движок: Godot 4.7.2 stable (headless) · База: `dfabb5f` (Этап 3: архитектура 8×3 + эволюция Берсерки)

## Итоговый статус: **PASS**

Валькирия (`valkyrie`) — второй полноценный, выбираемый в лобби класс с тремя
формами, настоящими боевыми механиками (канон `GAME_DESIGN.md` §6.1) и
автоматическими тестами (offline + сетевые). Берсерка не изменялась
(регрессия подтверждена); общие компоненты расширены обратно-совместимо.

## 1. Что реализовано

### Форма I «Валькирия» (меч, стальные тона)
- **Активное умение (E / ПКМ): рывок с круговым ударом** — сервер-авторитетное
  (`sv_request_action("skill")`, sender==owner): направленный рывок 17 м/с
  (0.26 с, движение через move_and_slide — стены останавливают, сквозного
  прохода нет), в середине рывка ОДИН радиальный проход урона 3.0 м
  (×1.1 урона атаки = 24.2, отбрасывание 9). Каждая цель поражается не более
  одного раза за активацию (одиночный проход, не тик). Cooldown 5.0 с;
  недоступно в DOWN/ATTACK/DODGE/SKILL. Урон идёт через штатную pipeline
  (`Units.make_damage` → `HealthComponent.take_damage`, attacker_peer →
  статистика матча, XP-вклад, однократные награды).
- **Пассивное парирование (F)** — окно 0.30 с, cooldown 5.0 с. Хук
  `try_parry_hit(damage)` вызывается из `HurtboxComponent.receive_hit` и
  `SpitProjectile._hit_hero` ДО урона (расширение на снаряды уже работает).
  Успех (ровно один раз за активацию окна): урон полностью отменён; защитный
  бонус (входящий урон ×0.65 на 2.5 с, складывается с прогрессией); следующая
  ближняя атака усилена ×1.7 (снимается после одного взмаха); контратака —
  круговой удар 3.2 м ×0.8. Неудачный тайминг (окно истекло) — урон полный,
  бонусов нет. Повторные попадания в рамках активации бонус не дублируют
  (окно расходуется), спам ограничен cooldown.

### Форма II «Клинковый танец» (уровень 3, парные клинки, свечение)
- +12% дальность ближней атаки (`melee_range_scale` → масштаб hitbox-сферы);
- **дополнительный удар в каждом взмахе** (`combo_extra_strikes=1`: повторная
  активация хитбокса в фазе восстановления; 2×25 = 50 урона по одной цели);
- усиленное парирование: окно 0.45 с, защита ×0.55/3.0 с, усиление ×1.9,
  контратака 3.8 м ×1.0; рывок 18 м/с, волна 3.4 м ×1.2, cooldown 4.5 с;
- статы: 130 HP / 25 урона / скорость 7.8; заметный визуал (парные клинки,
  свечение отделки, сапоги/наплечники, масштаб 1.03).

### Форма III «Багровая богиня» (уровень 5, багрово-золотая, аура)
- **зеркальные копии**: 2 серверных эхо-удара (×0.5 урона, интервал 0.22 с)
  повторяют КАЖДУЮ атаку (взмах и круговой удар). Не отдельные сущности:
  очередь `_phantom_queue` (лимит 4) тикает в `_server_sim`; урон копий не
  вызывает `on_hit_landed` → рекурсия/новые копии исключены; смерть пешки
  очищает очередь. Визуал — локальные полупрозрачные силуэты
  (`VisualFx.phantom_slash`, группа `phantom_fx`, ~0.5 с, автоочистка);
- **цепные удары**: первый подтверждённый удар взмаха переходит на 2 ближайших
  врагов в 4.2 м от первичной цели (×0.6, один раз за взмах —
  `_chain_done_this_swing`);
- **особая контратака идеального парирования**: 4.5 м, ×1.4 (40.6), стаггер
  0.6 с всей группе;
- +18% дальность, 29 урона, 155 HP, скорость 8.0, рывок 19 м/с (волна 3.8 м
  ×1.3, cooldown 4.0 с), багровая аура-кольцо и парящие осколки.

### Интеграция (правила §5 соблюдены)
- единый `PlayerPawn`, данные форм в существующем реестре `Classes`
  (`implemented=true` у Валькирии — доступна в лобби; серверная валидация
  `_sv_set_class` через `is_selectable`); репликация формы — существующее поле
  `"f"` BodySync (новых сетевых сущностей нет); пешка при эволюции не
  пересоздаётся — позиция/HP/cooldown/улучшения/owner_peer сохраняются;
- клиент не определяет урон, не подтверждает парирование, не разблокирует
  формы, не создаёт авторитетные копии — только просит (reliable RPC) и
  рисует локальную косметику;
- Берсерка не тронута: все новые поля данных нейтральны по умолчанию,
  хук `try_parry_hit` при `parry_window=0` всегда возвращает false;
- новые действия ввода `skill` (E/ПКМ) и `parry` (F) ДОБАВЛЕНЫ, существующие
  привязки не изменялись;
- баланс (§6): Валькирия мобильнее и сильнее в тайминге/контроле, но её
  одиночный урон и танковость ниже Берсерки (22→29 против 26→36 урона,
  110→155 против 120→190 HP) — «не сильнее во всех ситуациях».

для машины с ≥4 ГБ RAM: запустить 1 процесс `+dedicated` и N процессов
`+autotest=client +ip=<адрес>`.

## 4. Дефекты, найденные и исправленные в ходе этапа

1. `EnemyBase` не имеет `on_damage_received` (интерфейс пешек/пропов): прямой
   вызов в контратаке/цепочке давал SCRIPT ERROR и обрыв цикла — заменено на
   штатный путь (реакция врага через сигнал `damage_taken`). Найдено smoke.
2. Тестовая коллизия: цепной удар выбирал «лишние» цели из предыдущих секций
   (остатки пробных врагов в радиусе) — добавлена изоляция проверки (аналог
   `_isolate`). Это фикс теста, не кода.
