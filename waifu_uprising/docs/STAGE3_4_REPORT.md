## 2. Выбор источника модели (задача №2)

   в насильственных выражениях** → несовместима с боевым экшен-roguelite. ОТКЛОНЕНА.
2. **VRoid-сэмплы / MMD-модели** — лицензии ограничены тестированием VRM-софта либо
   некоммерческим использованием; боевых анимаций нет. ОТКЛОНЕНО.
3. **Sketchfab / CGTrader / Tripo** — загрузка требует аккаунт/API-ключ, которых нет
   (и выдумывать их запрещено условиями этапа). ОТКЛОНЕНО.
4. **KayKit Character Pack: Adventurers (Kay Lousberg)** — **CC0 1.0 Universal**
   (без ограничений, включая коммерческое использование): профессионально
   смоделированные хиби-персонажи с полной боевой анимацией. Официальное зеркало на
   GitHub, загрузка без ключей. **ВЫБРАН** как источник геометрии, текстур и анимаций.

Итоговая модель — производная сборка проекта из CC0-частей + оригинальные элементы
(крылья, палитра, оснастка), т.е. юридических ограничений не наследует.

## 3. Конвейер `tools/build_valkyrie_art_glb.py`

Запуск: `blender --background --python tools/build_valkyrie_art_glb.py -- <outdir> [composition]`
(переменная окружения `KAYKIT_DIR` — путь к Character Pack: Adventurers).

Состав базовой формы I (`valkyrie_art_f1.glb`):
- голова/лицо/волосы — `Rogue` (женственное лицо, причёска); рыжий перекрашен в
  платиновый блонд HSV-сдвигом атласа (порог по насыщенности отделяет волосы от кожи);
- латный комплект без шлема (торс, руки, ноги, плащ) — `Knight`; красные акценты и
  плащ перекрашены в глубокий синий, туника-зелень Rogue → ледяной синий;
- оружие: меч `1H_Sword` (кости `handslot.r`) + круглый щит `Round_Shield` (`handslot.l`);
- **крылья Валькирии** — оригинальная геометрия: веер из 6 маховых + 4 кроющих перьев
  на сторону, два слоя, внахлёст; скиннинг на новые кости `Wing1/Wing2.L/R`
  (имена совпадают с ригом этапа 3.2);
- узел `WeaponPivot` (bone-parent к `handslot.r`);
- рост нормирован к 1.78 м (масштаб рига 0.821);
- анимации: 8 контрактных имён переименованием боевых клипов пака:
  `Idle→idle`, `Running_A→run`, `1H_Melee_Attack_Slice_Diagonal→attack`,
  `2H_Melee_Attack_Spin→skill`, `Block→parry`, `Hit_A→hit`, `Death_A→death`,
  `Spellcast_Raise→transform`; **root-motion (X/Z кости root) вырезан** — пешку
  двигает код игры, анимации стали in-place;
- экспорт: GLB, Y-up, тангенты, NLA-треки → ровно 8 клипов.

Характеристики: **45 костей, 8 анимаций, 5055 треугольников, 3 материала
(PBR + текстуры 1024²), 801 КБ**. Старые модели f1/f2/f3 не удалены и не изменены;
`tools/gen_valkyrie_glb.py` не тронут.

## 5. Ограничения и следующие шаги

- Стиль базы — стилизованный хиби (пропорции источника CC0). «Чистое аниме»
  (VRoid-класс) для боевой игры юридически недоступно без платной лицензии
  (см. п.2 отчёта) — это осознанный компромисс этапа.
- Формы II/III пока остаются procedural-моделями этапа 3.2: конвейер параметризован
  (`composition`, палитра, оснастка) — эволюции собираются тем же скриптом
  (другие донорские части/палитра + узел `Aura` для формы III) без правки боевого кода.
- Крылья статичны в клипах (кости Wing1/2 не анимируются паком) — декоративный слой,
  как и на этапе 3.2; при желании добавляются procedural-взмахи в Godot.
