## Ключевые решения
- Не мутировать ClassDefinition в рантайме: эффективные статы считаются из базы × модификаторы (сервер).
- XP: вклад по урону (пропорционально), монеты: убийце; всё однократно через died-сигнал.
- Командные улучшения (резонанс) копятся на Гигачаде (сервер).
- Снаряды: серверная симуляция, спавн через MultiplayerSpawner, BodySync-интерполяция, lifetime+лимиты.
- Разрушаемые: событийные RPC (не пер-кадр), обломки локальные/косметические с временем жизни.
- Тесты: существующая инфраструктура (smoke_runner, autotest_runner, run_net_test.sh) расширяется, не заменяется.
