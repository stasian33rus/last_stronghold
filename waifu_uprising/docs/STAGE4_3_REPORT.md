# Этап 4.3 — разрушаемые объекты и боевые ловушки

База: `60f5854625b98ef82b635be07fbf9954ef10977e`.

## Аудит (что уже было)
- `DestructibleProp` (scripts/gameplay/destructible.gd): серверное здоровье, стадии
  повреждения, однократное разрушение (guard `is_destroyed`), событийные RPC,
  локальные обломки-RigidBody с таймером жизни, перепекание NavMesh; награда
  `grant_prop_reward` подключена в arena_01 (`destroyed_by`).
- Пробелы: на арене не было размещено ни одного ящика (ext_resource объявлен,
  узлов нет); ловушек не существовало; обломки не имели глобального предела.

## Реализовано
- **Размещение**: 4 ящика (боковые укрытия, вне спаунов) + 3 ловушки на арене
  `arena_01.tscn` (разные `start_offset` — циклы рассинхронизированы).
- **Ловушка `PulseTrap`** (scripts/gameplay/pulse_trap.gd + сцена): переиспользуемый
  тип; состояния IDLE -> WARN -> ACTIVE -> COOLDOWN -> IDLE; телеграф-диск на полу
  (прозрачность/эмиссия/мигание в WARN) + короткий звук; урон и отбрасывание только
  в ACTIVE, не чаще одного раза за активацию на цель (hit-once словарь), выход из
  зоны исключает цель; friendly fire выключен (`affects_players=false` по умолчанию);
  состояние реплицируется событийным reliable-RPC `fx_state` (клиенты зеркалят).
- **Предел обломков**: глобальный кап 32 тела на сцену (`DEBRIS_GLOBAL_CAP`),
  очистка по таймеру жизни сохранена.
- Серверная авторитетность: урон/уничтожение/состояния/награды — только сервер;
  клиенты получают событийные RPC; протокол ENet не менялся.
